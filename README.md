## The entry

One job title, the weirdest we could invent — a real-sounding senior role
with one gloriously specific twist:

> Senior Penguin Wrangler for Billionaire Yacht Parties

It reads like a genuine posting, it is specific enough to picture the
person doing it, and the twist lands on the first read.

## How it runs

`main.py` (Python 3.13, standard library only) writes exactly one line,
the job title above, to `/output/entry.txt` in UTF-8.

```sh
python3 main.py
cat /output/entry.txt
```

The title is 53 characters, inside the competition's 1-to-60 character gate.
